# React Movie projects 
This is based on React and vite. It uses react bootstrap for the designing.

It fetches top and popular movies from the pages

Custom fonts are added inside the src/fonts
custom hooks are added in the  folder src/customhooks
Added all the functional components in the folder src/components


# Using Public apis
- https://www.themoviedb.org/

- Register of api key https://www.themoviedb.org/
- Activate the account
- Once activated open the settings and click on the api as a developer mode
- Create api key by filling out the required information
- Access the api key.
